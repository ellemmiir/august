ILoveSchool

Платформа для краудфандинга школьных проектов

Сайт помогает школам собирать деньги на мероприятия, а спонсорам — находить достойные проекты.

О проекте

ILoveSchool — это платформа, которая соединяет школы, нуждающиеся в финансировании, и спонсоров, готовых поддержать образовательные инициативы.

Функционал сервиса делится на две части: для школ (авторов проектов) и для спонсоров. Школа подает заявку на краудфандинг: ее рассматривают и одобряют эксперты. Далее технология платформы продвигает проект, чтобы быстро привлечь инвестиции.

Задача

Разработать платформу с нуля, которая будет:

  • Принимать заявки от школ
  • Собирать инвестиции от спонсоров
  • Отслеживать прогресс каждого проекта
  • Быть понятной и удобной для обеих сторон

Как решили

  • Спроектировали удобную структуру для двух ролей: школы и спонсоры
  • Реализовали систему заявок и модерации
  • Настроили интеграцию с платёжной системой
  • Сделали простую и понятную админку для управления проектами

Почему дизайн получился именно таким

Мы сделали акцент на доверие и прозрачность. Использовали чистые цвета, минимум декоративных элементов, максимум внимания — на контенте. Интерфейс простой, интуитивный, с минимумом кликов до целевого действия.

С какими сложностями столкнулись

Задача:

Нужно было реализовать сложную систему модерации заявок.

Решение:

Разработали многоступенчатый процесс проверки: школа подаёт → эксперт проверяет → спонсор видит только одобренные проекты.

Задача:

Клиент хотел видеть статус каждого проекта в реальном времени.

Решение:

Внедрили шкалу прогресса, обновляющуюся автоматически при поступлении новых инвестиций.
